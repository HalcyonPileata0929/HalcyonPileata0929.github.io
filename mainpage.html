找牛找猫

一款纯前端、零依赖的逻辑推理小游戏。每行、每列、每种颜色区域里各藏一只动物，你要靠推理——而不是运气——把全部动物找出来。

关卡由算法实时生成，保证唯一解且可纯逻辑推导（不需要瞎猜）。支持「教学模式」（一个固定关卡分 6 步手把手教学，不自动排除、白叉全靠自己标）、「闯关模式」（前 25 关 5×5→9×9 阶梯，之后随机难度）与「自由练习」，每关随机换成找牛或找猫；色块大小从 1 格到多格都有，组合更多样。

技术栈：原生 HTML / CSS / JS · 内置 Web Worker 后台生成 · 离线可用

保卫阿斗

三国题材的文字合成塔防。上半是 AI 对手，下半是你，各守各的「斗」，山路每局随机生成，小怪不会穿过交战线。征兵抽「刀 / 枪 / 弓 / 骑」字牌拖到路边布防，同字同级合成升级，凑齐一个名字就能合体成武将。武将分传奇 / 史诗 / 稀有（橙 / 紫 / 蓝）三档，19 位里有七组共享字可互相喂级；兵器决定职业与技能（刀剑横扫、长杆冲锋、弓箭箭雨）。

打赢赚金币，去商城买 18 件武器和 12 件道具（主动 4 + 被动 8，另送 3 件永久开局加成），回主界面「装备 / 道具」面板装配，跨局保留。主界面两个模式：天梯赢加星、输扣星、连胜额外加星，每 5 星升一段共 10 段、每天清零，难度高金币多；匹配是常规难度，金币较少。顶栏还能切 1× / 2× / 3× 变速。

技术栈：原生 HTML / CSS / JS · 每次开局随机生成山路与阵地 · 支持 1×/2×/3× 变速 · 手机一屏可玩

关于我

森爷

我是 森爷，一个喜欢用 AI 和代码把想法落地的玩家。比起空谈概念，我更乐意做出一个「打开就能用」的小东西。

这个站点用来沉淀我做过的 AI 作品。每一个都尽量做到：自包含、可运行、有意思。「找牛找猫」是完全在浏览器里跑、关卡由算法保证可解的逻辑游戏；「保卫阿斗」是同一个人写完的塔防——每关的山路和阵地都随机生成，字牌合成武将是它的核心玩法。

后面的作品会陆续补充，方向包括但不限于：小游戏、效率工具、AI 玩具。如果你有想看的东西，欢迎来 GitHub 找我。
